# DeenAlhaq Config

ملف `app_versions.json` تقرأه تطبيقات دين الحق لعرض حوار التحديث.

## الحقول لكل تطبيق (المفتاح = packageName)
| الحقل | المعنى |
|---|---|
| `latest_version_code` | آخر رقم بناء (versionCode / Build) منشور على المتجر. لو نسخة المستخدم أقل → حوار تحديث اختياري (زر "لاحقاً"). |
| `latest_version_name` | اسم الإصدار المعروض للمستخدم (مثل 2.0.1). |
| `min_version_code` | أقل نسخة مسموحة. لو نسخة المستخدم أقل → حوار إجباري بدون إغلاق. `0` = معطّل. |
| `store_url` (iOS فقط) | رابط App Store للتطبيق. لو فارغ لا يظهر الحوار على iOS. |
| `release_notes` (اختياري) | `{"ar": "...", "en": "..."}` نص يظهر في الحوار. |

- `enabled: false` في أعلى الملف يوقف الحوار في كل التطبيقات.
- ⚠️ حدّث `latest_version_code` **بعد** ما النسخة تظهر فعلاً على المتجر.
- قد يستغرق التحديث حتى ~5 دقائق ليصل للتطبيقات (كاش GitHub).
